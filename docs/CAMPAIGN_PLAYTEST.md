# 五域归衡主线试玩

主线版从「五域游历 / 主线」进入。Windows 新包使用 `outputs/campaign-preview/windows/Play.vbs`；先前的 `commercial-preview/windows` 是三关 r2 试玩版，不会自动更新。主线版默认使用自己的 `data-save`，可注册新的测试账号；旧账号和旧窗口保持各自的数据。

## 从第一条线索开始

1. 注册并登录，选择本人角色，点击左侧「五域游历 / 主线」。顶部显示当前目标、冒险等级与距下一级的历练。
2. 默认从苍梧林开始。点击「听取线索」，读完对白后「记下线索」，再「前往本章秘境」。对白可以回看，确认线索会保存。
3. 首关朽梁可以从零资源、零装备开始；不需要添加家人或提交健康资料。照生乡试灯是可选教学，不会卡住旧三关进度。
4. 战斗使用 WASD 移动、J 普攻、1 剑诀、2 / 空格踏云、3 / K 护体、4 / R 归元。普攻命中回灵；看清预警后移动，抓住收招反击。正式秘境里的归元可以直接使用。
5. 胜利后获得历练、灵气、锻材及首通装备。到聚宝阁穿戴装备并强化，再继续下一关。角色基础属性随冒险等级提升，装备与套装在入场时加入。
6. 完成木域三关后，返回本章剧情，读完归衡对白并领取章节奖励。领取前会显示资源数量；同一章节只发放一次。点「继续主线」前往丹霞岭。

## 等级、奖励与恢复

- 冒险等级最高 30，历练来自正式秘境首通、再战和章节奖励。主线页显示当前与下一级的基础生命、攻击、防御、灵力和体力；装备另计。它独立于健康任务的修为，不会生成健康档案。
- 本人 HUD 显示冒险等级、正式秘境首通数与归衡印数。公开匹配和好友论剑继续使用统一基础数值，冒险等级与装备不会形成对战数值差。
- 每关最多 180 秒，短暂断线时战斗冻结，累计等待重连最多 15 秒。返回同一局即可继续；失败、离开或进程中断不发胜利奖励。
- 请求超时先刷新主线或秘境列表。已确认的对白、首通、章节奖励和历练由服务端保存；回看与重复确认不会再次发奖。
- 更新数据库采用追加迁移 10。旧三关首通、装备、钱包和祈愿保底保留，旧正式首通的历练仅补记一次。旧 r2 程序不能打开已经升级的库。

要保留旧账号，请依照 [数据库恢复指南](DATABASE_RECOVERY.md) 先备份原库，再恢复至新的 D 盘路径，用 `XIUXIAN_DESKTOP_DATA` 指定恢复副本。不要把不同版本同时指向同一存档，也无需删除旧库。

## 本轮验证范围

服务端构建及 96 项回归通过。独立新账号使用实际移动和技能输入，仅靠正常首通与章节收益完成 20 个 Boss、9 章奖励、结局与重启恢复，没有赠送装备或反复刷关。后 16 关每关三种招式及最终阶段专属招均实际执行，理想测试控制器每关约 35–71 秒；这不代表不同熟练程度玩家的实际用时。

源码原生 GL 联调覆盖真实注册、木域三关、所得装备付费强化、一次性章节领奖、对白回看、关闭重开、HUD 同步与进入火域。另有 20 个战场的数据渲染检查；其中强制阶段的图形样本只验证显示，不证明自然通关。

可复现入口：`npm.cmd --prefix server run check`、`node tools/playtests/story-ui.mjs`。自然养成和机制回归位于 `server/tests/campaign.test.ts`、`expedition-engine.test.ts`；运行记录在项目 `work/campaign/`，源码 GL 报告在项目父目录的 `outputs/story-preview/`。Windows 交付包的实际文件与冷启动验证以对应 `manifest.json` 及打包报告为准。
