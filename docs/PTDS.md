# PTDS 穿戴修行与神遁榜

网页与 Windows 正式版统一版本：2026.11.27-shendun-v1；共用 https://madxiuxian.com 的账号和服务端规则。Windows 解压后运行 Xiuxian.exe，不需要自建服务或配置模型密钥。旧版客户端需要重新下载；网页与程序端在同一账号的同一本人角色上操作。

## 本机导出

先在本人的 PTDS 中完成设备授权、同步和保存。使用 Python 3 在本机执行：

```powershell
python tools/export_ptds_summary.py --port 8780 --space YOUR_SPACE --date 2026-11-27 --source oura --output D:/Projects/ptds-20261127.json
```

日期使用当天，地址端口使用实际本机 PTDS 端口。`--source` 支持 `oura`、`garmin`、`somaloop`，只读取公开代码已经明确投影的日指标。导出工具不会授权设备或同步厂商账号；WHOOP、小米自动连接，以及 SomaLoop 睡眠投影尚未完成，不能仅因界面存在名称就认为已接通。缺失值不补造，瞬时序列和未知单位不猜测成日汇总。SomaLoop 原生 SDK 需手机桥接及相应使用授权。

Oura、Garmin 的明确日指标和 SomaLoop 的现有日投影可在本机预览，包括步数、睡眠（来源支持时）、HRV、心率相关指标、血氧、呼吸、温差、热量、恢复和压力评分等。每次使用新的输出文件名；文件含个人数据，请自行保管。完整字段与规则见 [转换方案](WEARABLE_GAME_MAPPING_V1.md)。

## 本人确认

登录并切换到本人角色，进入「同道录 → 神遁榜 → 导入今日穿戴数据」，选择 JSON、核对后点击「确认本人今日记录」。旧 Oura v1 JSON 仍可导入。仅今日记录可激活，游戏日按北京时间。确认页显示原始指标供本人核对，游戏服务端只接收日期、来源、有限档位和换算后的遁行丈数，不上传其他原始生理读数或厂商令牌。

PVE 轻身最高 +3% 移速、回气最高 +4% 自然体力回复、护体最高 +2% 防御；当天首次确认后锁定，不因重导或换设备叠加，不影响 PVP。每场 PVE 使用开场快照。每日奖励复用原有账本，与其他同组每日任务共用一次，不另发第二份。

## 神遁榜

1 步＝1 丈，按有效遁行距离降序排列，同分并列。全服榜和好友榜均有今日 / 本周，好友榜由服务器检查双向好友和屏蔽关系。多个设备只选一个步数来源，同日新数据覆盖旧数据，不累加；向下更正也同步降低距离。日汇总不能与分钟序列重复计算。榜单距离不封顶，战斗加成仍封顶。

默认不公开，可选择仅好友或全服及好友。公开内容为游戏昵称、头像、名次与距离，不显示名为步数的字段；但固定比例可反推出具体步数，这不是不可逆脱敏。撤回今日记录会停用当天加成并移除当日成绩，不会再次发放已领取奖励。记录为本人确认，不是硬件防作弊认证，不绑定有经济价值的榜单奖励。

同账号的服务器角色和确认记录跨端同步；本地设备授权、导出文件、登录令牌和设备设置分别保留在各设备，不会自动传输原始健康文件。
