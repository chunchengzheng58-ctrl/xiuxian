## 本次交付范围

### 九章二十关剧情

- 主线统一为《按时吃饭》，包含九章、二十个正式秘境。
- 每关拥有独立战前与战后场景，共 40 个；另有独立回村结局 `ending.home`，合计 41 个场景。
- 原有关卡前置、战斗数值、攻击范围、判定、预警、首通/再战奖励、章节奖励和顺序解锁保持不变。
- 父亲不以残魂长篇告别，不安排复活式圆满；情绪落点保留在旧灯、树痕、家书、空船、冷杯、三碗面和“锅里还有”。

### 播放、跳过、回看与恢复

- 共用剧情播放器支持上一句、继续、跳过、回看、空格/回车/方向键及模拟触屏按钮。
- 首播和跳过只写对应场景标记，不发奖励、不提交战斗胜利；重复完成保持幂等。
- 回看不再写标记，也不会在看完战后场景后擅自再开一场战斗。
- 场景保存失败会明确返回未保存；战前保存失败不会直接跳过关卡进入战斗。
- 断线恢复战前后使用原 `run_id` 回到原战斗，而不是误传关卡 ID。
- 旧档已通关关卡可补看战前、战后；最终 Boss 战后完成后自动接入“回村吃面”。剧情加载或播放期间不能误关结算页。

### 男女主角与同行者

- 男女主角共享完整九章、二十关、伏笔、奖励、旗标与结局。
- 阿宁可独立选择男/女外观，不与主角性别绑定，不改写为其他亲属关系。
- 四种组合均使用同一套正式 campaign；父母统一称“孩子”。
- 占位画面被拒收后，`b12` 家书页与 `ending.home` 已改用正式场景和真实角色立绘；家书直接显示可读正文与划改，回村页显示母亲、主角、阿宁同桌及三碗面、一副旧碗筷，不再使用方块人物或空白信。
- 四种男女主角／阿宁外观组合均已分别实渲；男阿宁使用项目既有绿衣书卷青年素材，女阿宁使用既有地图筒角色母版。

## 本地试玩

双击桌面 `疯狂修仙，中`，或运行项目根目录 `启动试玩.cmd`。该入口直接使用当前 Godot 工程，不是旧官网或旧导出包。

1. 登录/注册并选择本人角色。
2. 打开“五域游历 / 主线”或本章秘境。
3. 首次进入关卡会先播战前；看完或跳过后进入战斗。
4. 首通胜利后自动播放战后；结算页也可手动打开“战后 · 归途留言”。
5. 最终关战后结束后自动回村。以后可从主线章节回看，不会重复发奖。
