## 1. 一句话故事与制作真相

### 1.1 玩家实际经历的故事

孩子离家去修五域的灯，以为只要把事情做完，远门未归的父亲就能回来。一路上，有人留饭，有人留灯，也有人悄悄跟了上来。等孩子终于走到常生台，才发现旅途并不是把父亲带回来的路，而是学会在没有父亲的日子里，仍按时吃饭、仍愿意回家的过程。

### 1.2 只对制作组公开的真相

- 青松在故事开始前已经离世。主线中不安排正式讣告、灵魂现身、临终录像或长篇遗言。
- 母亲、雷叔、陶伯、汀兰先后知道或猜到事实，但他们不以“替孩子好”为理由继续编一个圆满谎言；他们只是把日常维持到孩子自己能承受答案的时候。
- 阿宁最初答应留在照生乡，随后独自出发追赶玩家。阿宁不是等待被救的附属角色，而是测绘师兼守灯匠，能修绳结、认水路、标安全线；其冒险来自“不愿让玩家独自走完”，不是无知冲动。
- 执衡不是单纯反派。他把常生台留在青松最后一次来下棋的时刻，不肯接受有人不会再回来。冻结五域不是宏大理想，而是一个不肯收拾残局的人。
- 玩家不能救回青松，也不能“治好”所有守关者。归衡只解除当前的阻塞，给仍在生活的人留一条继续前行的路。

### 1.3 真正的情绪高潮

最终 Boss 战只负责解开世界，不负责解释人生。真正的回收发生在结尾：

母亲看见阿宁一起回来，只多拿一双筷子；她本要把另一副旧碗筷收起，玩家说“放着吧”。桌上是三碗面，灶台边还放着一副没有人用的碗筷。面里没有葱。玩家吃到一半，才把那封被划掉归期的家书、母亲准备的两份干粮、渡口那艘空船重新连起来。

不对白解释，不出现父亲幻影，不闪回死亡过程。

## 2. 写作与演出总规则

### 2.1 三条感情线，三个动词

| 感情线 | 核心动作 | 重复物件 | 最终含义 |
|---|---|---|---|
| 父爱·青松 | **放手**：把归期划掉，把最后一条路留给孩子 | 树痕、木剑、家书、碗、空茶杯 | 父亲没有把答案留下，只把生活的方法留下 |
| 母爱·母亲 | **等待**：不把孩子困在家里，也不让家变成审讯室 | 双份干粮、门灯、针线、第二副碗筷 | 回家不需要先成功，也不需要先解释 |
| 爱人·阿宁 | **同行**：嘴上说顺路，实际一步步把险路先走一遍 | 绳结、药包、地图、同行干粮、袖口的伤 | 爱不是替对方决定，而是让对方有路可回 |

### 2.2 留白纪律

1. 主要人物不直接说“爱、牺牲、永远、舍不得、我都是为了你好”。
2. 每名 NPC 连续最多说一句带情绪的话，下一句必须回到修桥、添水、收碗、看路等日常动作。
3. 一次场景只留一个关键物件，不堆三四个“催泪道具”。
4. 真相节奏固定：木域疑惑 → 金域不安 → 水域明白 → 回村后彻底反应过来。
5. 不用旁白替观众总结“这就是父爱/母爱/爱情”。能由动作表达的，不写解释句。
6. 不写疾病名称、诊断、器官台词或“烧坏脑子”。失简、晦鳞、执衡均不是任何现实疾病的拟人化。
7. Boss 不是“坏人被打死”。统一使用“归衡、退下、停下、让开、散去”等结果语言。
8. 战斗短句不能遮住预警，不暂停输入，不在玩家需要闪避时弹整屏对白。

### 2.3 台词尺度

- 剧情面板：每句建议 8–24 个汉字；关键停顿句可以只有 2–6 个字。
- Boss 战斗短句：每次 2–10 个汉字，显示 1.2–1.8 秒；单场最多三次，不与高伤预警同时出现。
- 无口型动画时，不安排长段正面说话特写；采用背影、手部、道具和侧脸。
- “……”不能代替所有表演。每次省略号都必须对应一个可见动作，如收信、转身、把碗推近。

### 2.4 男女主角共线与差分

- 男女主角使用完全相同的九章事件、二十关顺序、伏笔、Boss 动机、抉择与结局，不把女玩家做成男版换皮，也不另写一条被保护、被等待或被劝阻的弱化路线。
- 父爱、母爱不因主角性别改变。统一以“孩子”称呼，不使用“儿子该怎样/女儿该怎样”“男子汉不能哭”等性别规训；男女主角都被允许沉默、疲惫、回头和继续吃面。
- 阿宁的测绘、修绳、先行探路、带伤同行和终章引路作用完全共用。同行者外观提供女性与男性两个同身份版本，名称同为阿宁，玩家独立选择，不由主角性别自动配对，也不把任何组合改写成兄妹或突然删除感情线。
- 同行者差分只涉及立绘、少量发型/体态、称呼和配音；服装功能、图筒、浅杏色围巾、绳结、动作节拍与剧情旗标一致，避免两条线后期维护成不同故事。
- 结尾“那多拿双筷子”“放着吧”“锅里还有”对所有组合原样成立，不使用性别刻板笑料，不让母亲只对某类组合表达接纳。
- 运行时保存 `protagonist_variant` 与 `companion_variant` 两个独立显示字段；它们不进入关卡奖励、真相旗标和章节完成条件。
- 验收至少覆盖男/女主角 × 男/女阿宁四种显示组合，检查台词、立绘、动作、回村座位、存档和断线恢复均一致。

## 4. 二十关逐关剧情、Boss 语言与回收

> 下列“入场”用于战前秘境序幕或倒计时，不覆盖正在计时的战斗。  
> “短句”是可选战斗 bark，不是每招必说。没有台词的 Boss 用铃声、木响、呼吸、水声等动作语言。  
> 每关保留既有技能机制，新增的只是叙事原因和视觉反应。

### b00 听雷｜第一响

- **前情**：母亲把干粮分成两包，阿宁低头修门边旧绳，答应留在村里。玩家回头时，母亲只说“别回头，路不好走”。雷叔带玩家到旧灯座前，不解释自己知道多少。
- **Boss 自然入场**：雷叔摇第一下铜铃，云气在灯后聚成小雷兽；第二下没有摇完，小雷兽先接住铃舌，像在说“让他自己看”。它不是来杀人的，而是替青松完成最后一次入门考校。
- **战斗语言**：待机蜷缩护灯；蓄力先竖起两枚耳状云角，再展开雷环；受击缩成一小团云；败退时不爆炸，只把铃推到玩家脚边。
- **可选短句**：雷叔“先看，再动。”／战后“嗯。”
- **退场与回收**：灯亮，玩家取得铜铃。雷叔收走第二下铃槌，像收起一句没说出口的话。
- **资产**：旧灯座、双份干粮、铜铃、母亲打包动作、雷叔收铃槌动作。

### b01 朽梁｜不肯换的旧木

- **前情**：阿禾拿检修图比对桥缝，发现朽梁把新换的木料全顶了出来。旧桥是青松常走的路，桥上还有玩家小时候留下的一道歪刻痕。
- **Boss 自然入场**：玩家踩过中空桥板，脚步声从桥下返回；木麋驮着古桥从水里站起，四蹄仍死死扣住两岸。它不是拦路，是怕自己一松，桥就没了。
- **战斗语言**：横扫前身躯先压低、桥索先绷直；受击只掉旧漆不掉血块；破势时背上桥板短暂打开，露出中空木腔；败退后一根新梁填入，旧木麋退成守桥兽。
- **退场与回收**：阿禾换下朽木，没有全部丢掉，只把带刻痕的一小段留在桥头。
- **伏笔**：后来所有“守过了头”的 Boss，都与它形成同一动作：抓住不放。

### b02 涩节｜越紧越安全

- **前情**：机关坊的榫卯本可拆卸维修，涩节却把所有接缝咬死。学徒越上油，它越以为有人要拆散它。
- **Boss 自然入场**：工坊里一件木椅刚被碰歪，地面榫条立刻一根根合拢，拼成机关兽；它先检查玩家腰间木剑，再把剑鞘也当成“松动部件”。
- **战斗语言**：近战前四肢关节逐节锁死；签名技前胸腹齿轮倒转半圈；受击后木屑从接缝落下；激怒时不是发红，而是所有关节同时发出一声“咔”。
- **退场与回收**：玩家只卸开关键一榫，机关兽恢复活动，没有散架。
- **阿宁暗线**：出口的断绳已被重新接好，绳结很新。阿禾只说“前面的人手挺巧”，不提名。

### b03 窃荣｜花一直开着

- **前情**：旧祠里的花从不知谢，外围新苗却全被根蔓抽空。白鹿负着老槐，始终挡住树干最低处。
- **Boss 自然入场**：玩家伸手拨开一片花，白鹿立即以角护住树皮，繁花同时张开，根阵从两侧合拢。冲突来自玩家要看的不是花，而是树。
- **战斗语言**：蓄力时低头护住树干，根蔓先收缩再弹出；回血时花向鹿身聚拢；受击只落花；破势后背上的老槐露出真实年轮。
- **退场与回收**：花谢了一层，露出身高刻痕。最高几道旁是青松的记号，最新几道却是雷叔的刀法。
- **对白**：阿禾“后面几道……是你走后刻的。”随即蹲下收拾落枝，“这个还能做灯柄。”
- **章尾**：木印入手，不出现父亲幻影。

### b04 乱律｜报时的钟不肯走到下一刻

- **前情**：鼓楼把某一天的开饭声、风声、脚步声全留了下来，时刻一乱，火域再没人知道该何时封炉。
- **Boss 自然入场**：陶伯把一块炭放进炉中，鼓腹铜蝉却把旧时辰的鼓声原样敲回；双面交替响起，梁柱上的悬铃跟着错位共鸣。
- **战斗语言**：双面换向前先静止半拍；环音不是从凭空出现，而由腹部旧鼓皮一圈圈推出；激怒时所有旧声叠在一起，但预警仍清楚。
- **退场与回收**：杂声退去，只留一下准时报时。
- **对白**：陶伯“你爹饭做得不好。”他把碗翻过来洗，“倒记得你不吃葱。”

### b05 窄焰｜不敢让火歇一会儿

- **前情**：长明炉的焰道被一条赤鳞蛇越缠越窄。它见过灯熄，便认为只有一直烧着才算守灯。
- **Boss 自然入场**：玩家拧低第一盏灯，炉影里的蛇身立刻收紧；它沿灯柱盘起，把最细的一线火护在喉下，身后通道反而彻底暗了。
- **战斗语言**：出招前鳞片从尾到头依次亮；窄焰喷吐前蛇身先让出安全侧；受击时火光缩暗而不是全身盖白；败退后分段盘回灯座。
- **阿宁暗线**：背风处放着玩家常用的药包，外包装换过，里面的分装习惯没变。陶伯只说“有人给你留的”。

### b06 赤棘｜把保护长成壳

- **前情**：黑石山豕小时候受过青松喂食，后来便守着旧炉区不走。赤晶一层层长到它身上，也把桥、炉和路一起封死。
- **Boss 自然入场**：陶伯把旧食盆放到炉边，山豕从黑石后慢慢走出；听见玩家脚步，它又退到炉前，用背甲挡住所有出口。
- **战斗语言**：甩棘前先把前蹄插入石缝；受击时晶壳局部开裂；激怒不是冲撞加速，而是把旧食盆拱到身后，再正面迎上。
- **退场与回收**：晶壳脱落，食盆仍在。旧炉旁那盏灯座被擦得很干净。
- **对白**：陶伯“你娘每月来擦一次。”顿一下，只把抹布递过来，“搭把手。”

### b07 积璧｜什么破了都想留

- **前情**：穿山兽把碎瓦、裂玉、旧闸片全补进自己身上，也补进水渠。它不肯丢任何一块曾挡过水的东西，结果水再也过不去。
- **Boss 自然入场**：禾生揭开渠盖，水面没有流声；一片碎璧从淤泥里翻出，随后千百片沿渠壁立起，拼成玉鳞穿山兽。
- **战斗语言**：飞璧前背部鳞片先朝向目标；埋片前尾尖在水面点三下；受击只掉碎玉；破势后腹下露出被堵的旧闸。
- **退场与回收**：水通了，禾生把能用的瓦片分堆，不再全部塞回渠里。

### b08 薄丹｜给别人照路

- **前情**：纸灯蛾把沿途熄掉的灯全背在翼下，自己的翼膜越来越薄，却仍不肯放下任何一盏。
- **Boss 自然入场**：驿路尽黑，只有一点朱砂光飞来。玩家点亮第一盏路灯，薄丹却以为又要交出一盏，猛地把所有灯护进翼下，风压因此形成攻击。
- **战斗语言**：攻击前翅面合拢，留下清楚的安全侧；灯屑只从翼缘落下；受击时光变弱但轮廓不消失；败退后只保留一盏小灯。
- **阿宁暗线**：驿站地图边角多了一条细墨线，绕过深水，标法与 b02 绳结旁的小记号一致。

### b09 失稷｜仓里有粮，路上没有

- **前情**：陶甲地牛把谷仓驮在背上，怕再遇荒年，不肯开仓。仓里粮堆越来越高，末端田灯却越来越暗。
- **Boss 自然入场**：禾生敲仓门，里面先传出谷粒滑落声，随后地面隆起；地牛顶着仓房站起，第一反应不是攻击，而是用身体压住仓底裂缝。
- **战斗语言**：吞吸前仓门向内开，预警与风向一致；陶甲崩落前先出现旧裂纹；受击落下谷壳而非血肉；败退后仓门只开一条够出粮的缝。
- **退场与回收**：公仓旧账摊开，青松那一页只写“给孩子一份”，后面又添了母亲的名字。
- **对白**：禾生“你娘特意交代，干粮算双份。”他把账页压平，“去一份，回来一份。”

### b10 闭岚｜把冷风挡在外面，也把信挡住

- **前情**：青铜炉犀曾替白羽关挡寒流，后来再也不肯开风囊。寒气进不来，书信、鸟群和人都出不去。
- **Boss 自然入场**：素娘解开一条风带，墙内立刻传来沉重吸气声；炉犀从铸库深处倒退着坐下，用身体堵住主风道，满墙信件同时贴紧。
- **战斗语言**：蓄力时风囊先瘪后鼓；闭合前四肢分别扣住地面环扣；受击时甲片传出一声空响；破势后风囊裂开一线，先飞出的不是碎片而是信。
- **退场与回收**：风道重开，一封信从玩家头顶掠过，落款不是照生乡，而是白羽关。

### b11 灼羽｜护送不是替别人走

- **前情**：白羽鹭把余烬藏在翼下，给迷路人取暖；走得越久，它越不肯让任何人离开自己的翼影。
- **Boss 自然入场**：玩家刚带羽灯离巢，白羽鹭便横翼落在前路，翼下余烬照亮整片关隘。它不夺灯，只把归路一点点烧成不能回头的方向。
- **战斗语言**：展翼前先低头护住余烬；扇燃前左右翼有先后；受击只散白羽；激怒时余烬更亮，身体反而收小，保持主角与预警可见。
- **退场与回收**：素娘接过羽灯，白羽鹭终于让开半步。
- **对白**：素娘“先前也有个人路过。”她看一眼地图，“问你走哪边比较稳。”

### b12 缄风｜没寄出的信

- **前情**：铜羽长鹤怕信被风撕碎，总用双翼把信拢住；翼一合，信却再也送不出去。
- **Boss 自然入场**：素娘把最后一叠旧信放到石台上，铜鹤从天井落下，以翼覆信。玩家上前一步，错位玉环先转，风刃随后才到。
- **战斗语言**：蓄力时先收羽再抬环；受击时一张空信封飘落；破势后双翼打开，但身体仍挡在信前；败退后用喙把最旧的一封推向玩家。
- **关键道具**：青松家书。“等爹回来，给你下碗面”被划去，改为“按时吃饭”。画面只停纸面和玩家拇指，不给回忆旁白。
- **另一封信**：阿宁写“家里都好”，落款是白羽关。玩家这才知道阿宁不在村里。
- **章尾**：素娘继续分信，不解释任何一封。

### b13 沉砂｜水太清，就看不见从前

- **前情**：巨蚌把每场水患留下的砂都含在壳里，想用砂记录河流，结果渡口再没人看得清水下石阶。
- **阿宁重逢**：玩家在渡口先看见自己的地图摊在石上，阿宁正在压地图角。袖口有磨损，只解释“顺路”。不安排拥抱或追问长段。
- **Boss 自然入场**：阿宁把一块测水石放入水中，蚌壳在浅滩下闭合，砂幕顺着石阶升起，巨蚌托着旧渡碑露出水面。
- **战斗语言**：吞砂前壳内先变黑；双壳合拢有明确前后拍；受击落细砂；破势后壳内短暂露出一线清水。
- **退场与回收**：阿宁把地图递回，安全线已经画到下一关。

### b14 滞潮｜两边都放不下

- **前情**：单足夔守着内外河双轮，怕任何一边停转，便轮流把两边都卡住。越用力维持，潮水越无法通过。
- **Boss 自然入场**：阿宁在外侧轮架上拉紧校绳，双轮却反向咬合；水面立起两只轮影，夔从中间单足落下，先护住较近的那只轮。
- **战斗语言**：换轮前身体重心明显移向另一侧；水轮起动前先反转半寸；受击时单足短暂悬空；激怒后两轮仍按既有规则，不增加无预警伤害。
- **退场与回收**：校绳回弹，阿宁袖口被划开。玩家让其回去。
- **对白**：阿宁“等一起。”随后把绳重新缠好，“先把这个轮卸了。”

### b15 壅川｜拦了太久的水

- **前情**：玄龟把内河挡在背岳之后，怕下游再受水，年复一年，自己成了新的洪口。
- **Boss 自然入场**：汀兰翻开旧日志，水面反而完全静止；量水碑先从雾里立起，玄龟背岳随后升起，碑上的旧水痕与岸边刻度一一对应。
- **战斗语言**：水闸启动前背岳先倾斜；四转水轮按固定节奏换向；受击时碑面掉下旧苔；破势后闸门打开，龟首仍朝向渡碑而不是玩家。
- **退场与回收**：汀兰说青松曾在渡口坐了一夜。“第二天，船自己回来了。”停一拍，“是空的。”
- **留白**：她马上把水灯递来，“水凉了，先把灯带上吧。”阿宁不安慰，只站到玩家身旁。

### b16 漏夜｜今天总要亮起来（可选旁篇）

- **前情**：阿更守换夜刻，漏刻墨蛾却让月亮一直停在原处。大家都怕夜过去后，有些旧习惯也要跟着结束。
- **Boss 自然入场**：阿更拨动漏壶，水滴向上回到壶中；不落之月展开成墨蛾，村路的影子全被拉回同一方向。
- **战斗语言**：月相变化先于招式；受击只落墨粉；破势后月亮第一次向下移动；败退不是黑夜爆炸，而是远处天色慢慢变亮。
- **回村场面**：母亲给玩家缝破衣袖，不问青松，只问“这儿还磨不磨”。收针时说“下次破了，还拿回来”。

### b17 失简｜东西还在，名字淡了（可选旁篇）

- **前情**：渡船、茶杯、木椅都留在家中，却没人能说出该把它们放到哪里。空白竹简上的纸片蠹鱼专吃路标和旧签。
- **Boss 自然入场**：玩家把渡船模型放回木架，竹简上的字却一笔笔褪去；纸片蠹鱼沿墨迹游出，卷走“青松”二字，却保留物件本身。
- **战斗语言**：吞简前先展开空卷；拼阵前纸片按固定次序翻面；受击落空白纸屑；败退后字没有完全恢复，只恢复几条够用的摆放记号。
- **回村场面**：母亲找到针线，不找渡船。未完成的小木剑仍在原处。
- **对白**：阿宁“你出门以后，她每晚都点灯。”停一下，“天亮再熄。”母亲只喊：“饭要凉了。”

### b18 晦鳞｜一路没放下的东西

- **前情**：云墨妖龙由五域旧痕的残余缠成，重复着朽梁的撑、窄焰的缠、积璧的补、壅川的拦。它不是“所有恶念”，只是同样的执念在镜鳞里反复照见。
- **阿宁行动**：阿宁为提前标出安全路线先走一步，遇险后仍把地图护在最内层。玩家抵达时，阿宁先递地图，不先展示伤。
- **Boss 自然入场**：玩家把五域旧物放到相痕海边，水面逐一映出五域灯火；灯火没有熄灭，而是被一条镜鳞长龙串起，龙首从玩家自己的倒影里抬起。
- **战斗语言**：每换一种旧招，对应镜鳞先亮一域；旧招只保留原有可读预警，不叠加全屏特效；受击时鳞片映出灯而非伤口；破势后五域影像彼此分开。
- **退场与回收**：阿宁说“这一段，我走过了，跟紧一点。”五域 NPC 的灯在远处依次亮起。
- **额外回收**：阿宁的干粮袋与玩家同款，袋角有母亲的针脚。

### b19 执衡｜这盘还没下完

- **战前场景**：常生台只有一盘未下完的棋、两只茶杯。执衡给已经冷掉的那只杯子续热水。阿宁随后入场，没有替玩家作决定，只把回村的路灯点亮。
- **短对白**：玩家“他呢？”／执衡“走了。”／玩家“去哪了？”／执衡“不知道。”他看向棋盘，“这盘还没下完。”
- **Boss 自然入场**：玩家伸手收起一枚棋子，执衡第一次抬手阻止；五色环带停止流动，青铜衡臂从天仪外轮廓展开，棋局被固定在战场中心。
- **战斗语言**：阶段切换先由一枚棋子换位预告；五行招式只复用既有可读机制；受击时衡臂轻颤、茶水晃出，不大面积遮脸；激怒时所有声音停半拍，只有冷杯落回桌面的一声。
- **战斗短句**：开场“别动。”／转阶段“还早。”／低生命“茶还温着。”均为低音量短句，不连续独白。
- **败退动作**：五色环带逐条垂下，执衡没有跪地忏悔。它看向村树方向，问“外面，那棵树还在吗？”再问“长高了吗？”玩家答“高了”。执衡只说“哦”。
- **最后动作**：执衡把棋子一枚枚收回，最后留一枚在桌上。阿宁说“你娘刚才把面下锅了。”停一下，“再不回去，要糊了。”

## 5. 终章回村：完整结尾演出脚本

### 5.1 入村

1. 村路与序章同机位，季节或光色略变，布局不变，方便玩家认出同一扇门。
2. 门灯亮着。阿宁停在玩家后半步，不抢先进门。
3. 母亲先看见玩家，再看见阿宁，只把门推得更开一些。

**母亲**：回来了。  
**母亲**（看见阿宁）：那多拿双筷子。

### 5.2 收碗

1. 桌上原本有三副碗筷，母亲转身从柜边又拿起一副旧碗，像要收走。
2. 玩家伸手，不接碗，只轻轻按住桌沿。

**玩家**：放着吧。

3. 母亲点头，把旧碗放到灶台边，不摆在父亲遗像前，不点香，不解释。

### 5.3 吃面

1. 面端上来，没有葱。雷叔晚一步进门，手里仍拿着刻刀。
2. 阿宁把伤侧袖口往回收。母亲看见，只把凳子往阿宁那边拉近。
3. 灵宠趴在玩家脚边，没有抢戏。

**母亲**：咸不咸？  
**玩家**：不咸。  
**母亲**：那就好。  
**母亲**：锅里还有。

4. 玩家低头吃面。只闪回三个极短、无旁白的物件镜头：
   - 家书上被划掉的“等爹回来”；
   - 粮仓账页的“双份”；
   - 渡口空船的缆绳。
5. 回到桌面。没有人哭给镜头看。母亲转身去灶边，雷叔把刻刀收起，阿宁把一碗面往玩家方向推近一点。

### 5.4 终镜

镜头停在灶台边那副无人动过的碗筷，再缓缓移向门灯。门灯仍亮着，但天已经亮了。

**不显示**：主题总结、父亲灵魂、遗言旁白、“爱从未离开”等句子。  
**可显示**：章节完成、返回照生乡、继续经营与长廊挑战。  
**最终可交互句**：母亲“下次回来，提前说一声。”她顿一下，“我好烧水。”

## 6. 核心角色设定与动作优化

### 6.1 统一视觉方向

- 沿用现有三头身剑修、六名乡人与 Boss 动作图的清秀手绘像素感：头身比例、柔和暗线、低饱和乡村色、少量高亮灵力色。
- 新角色概念图采用 16:9 横版三视图，正面、严格侧面、背面同一角色，等高、同脚底基线，无场景、无文字。
- 实际游戏立绘另出透明底；战斗动作仍以 4×4、cell 384 的现有规范为准。剧情微动作单独建图，不挤占战斗帧。
- 不用大袖子、长飘带和复杂背饰遮挡手部。父母与阿宁的情绪主要靠手、肩、视线和物件位置。

### 6.2 主角（沿用现有男女剑修）

**身份锚点**：高马尾/束发、蓝白劲装、背剑、清楚的手部轮廓。  
**不改动**：现有 16 帧战斗动作、受击和技能轮廓。  
**新增剧情动作**：

| 动作 | 帧数建议 | 表演要点 |
|---|---:|---|
| 收信停顿 | 4 | 拇指在划掉的字上停一下，不抬头，不流泪 |
| 收干粮 | 4 | 把两包分开放，后来把其中一包递给阿宁 |
| 回望 | 4 | 肩先动、头后动，最后仍转回前路 |
| 树下站立 | 4 | 手掌比到最新刻痕，发现自己已高过旧痕 |
| 桌前吃面 | 6 | 第一筷正常，第二筷停在半空，随后继续吃 |
| 坐守空椅 | 4 | 不趴桌痛哭，只把背慢慢挺直 |

### 6.3 青松（新增身份母版）

**年龄与气质**：约 48 岁，清瘦、背略弯但不衰弱；是会修灯、会刻木头、饭做得不好的普通父亲，不画成完美仙侠英雄。  
**外形锚点**：短黑发夹灰、浅短须、旧青灰短褐、袖口有母亲补过的针脚、腰侧小刻刀、手提旧纸灯。  
**配色**：青灰与旧木色为主，灯芯暖黄只做小面积识别。  
**禁用**：仙气长袍、全身金光、悲壮雕像姿、持续微笑、正面遗像式构图。

**只用于旧痕与物证的动作**：

| 动作 | 用法 |
|---|---|
| 树前刻痕 | 只露手和刻刀，玩家无法确认完整面容 |
| 削木剑 | 未完成即停，木屑落在鞋边 |
| 灶边尝汤 | 自己先皱眉，仍把葱挑出来 |
| 渡口背影 | 仅一次远景，不回头、不招手 |
| 棋桌空位 | 不出现真人，只由对面冷杯和棋位表达 |

### 6.4 母亲（新增身份母版）

**年龄与气质**：约 48–52 岁，动作利落，头发有少量灰丝；不是终日哭泣的等待者，白天仍做事、与人来往。  
**外形锚点**：低髻、灰蓝外衣、暖褐内衬、腰侧针线小包、袖口便于挽起；干粮布袋与阿宁后来使用的袋子同针脚。  
**配色**：灰蓝、旧米白、少量枣褐。  
**禁用**：过量白发、病弱姿态、满脸泪痕、夸张慈祥光晕。

**剧情动作**：分装干粮、门边松手、缝衣、点灯、熄灯、收起旧碗、下面、把凳子拉近、转身烧火。  
**表情页**：平常、看向门外、低头做活、听见门响；四者差异集中在眼神和肩颈，不靠嘴型大哭。

### 6.5 阿宁（同一身份的双外观母版）

**年龄与气质**：与主角相近的青年，清秀利落、性别表达不做夸张刻版；测绘师兼守灯匠。女性与男性外观是同一角色、同一经历，不是性格不同的兄妹。  
**外形锚点**：短束发、青灰旅行衣、浅杏色围巾、斜背图筒、腰侧绳结与小工具、靴子便于走水路。男性版保持同一服装结构、配色和道具比例，只调整发型、脸部与适度体态差分，不做简单换头或换色。  
**配色**：青灰为主，浅杏色只用于围巾和地图标记，形成“人群中能认出”的小面积暖色。  
**状态差分**：常态；b14 后袖口磨损与手臂护带；b18 后图筒有擦痕，但不增加血污大面积覆盖。  
**禁用**：等待被救的哭姿、无理由逞强、替主角挡下每次攻击、爱情宣言、全程脸红；也不因玩家性别改变谁探路、谁被保护。

**剧情动作**：修绳结、压地图、标安全线、藏起伤侧、递干粮、先走半步、停在玩家身后半步、坐下吃面。

### 6.6 雷叔（沿用现有老人提灯形象）

- 新动作：收铃槌、续刻树痕、把厚衣服放到包袱最上面、避开玩家视线、结尾收刻刀。
- 语言规则：知道事实但不发表长篇解释；被问到时最多说“出门前，我就知道了”，下一句转为“衣服放最上面，晚上凉”。

### 6.7 区域 NPC（沿用六人图板，不重新造六套人设）

- 阿禾：桥与木器，动作以蹲身量木、收落枝为主。
- 陶伯：炉与碗，动作以洗碗、添炭、递抹布为主。
- 禾生：渠与公仓，动作以压账页、开仓、分粮为主。
- 素娘：风信与羽灯，动作以分信、接灯、看地图为主。
- 汀兰：渡口与水灯，动作以合日志、递灯、系缆为主。
- 阿更：漏刻与乡路，动作以拨漏壶、等天亮为主。

### 6.8 执衡（沿用青铜天仪人形外轮廓）

- 不另做“帅气人形反派”。其情绪由五色环带、衡臂、茶杯、棋子承担。
- 待机：环带缓慢、棋子悬而未落；受击：衡臂偏移；激怒：所有环带静止半拍；败退：环带逐条垂下，衡臂重新平衡。
- 面部即使保留现有面具，也不做夸张哭笑。最后的“哦”配收棋，不配面部特写。

## 7. 动画资产规格与复用方式

### 7.1 现有战斗图不推翻

- 路径：`assets/combat_animations/` 与 `data/combat/action_atlases.json`。
- 规格：4×4 共 16 帧，cell 384；0–3 待机/行走，4–7 近战，8–11 技能/签名，12–15 覆盖受击、破势与败退。
- 保留二十 Boss 的当前帧，只补场景入场、环境联动与少量姿态 tween，避免为每关另画一套战斗图。
- 主角技能色仍服从此前“暗红剑气、不过度遮挡”的战斗视觉规则，不为剧情改回大面积金色光弧。

### 7.2 新增剧情动作图

建议每名核心角色一张 `4×4 / cell 256` 剧情图，透明底、统一脚底 pivot。首版只填实际使用格，未使用格不占运行时内存。

| 行 | 帧位 | 通用动作语义 |
|---|---|---|
| 0 | 0–3 | 静立呼吸、视线偏移、回望、肩部放松 |
| 1 | 4–7 | 取物、持物、停顿、收起 |
| 2 | 8–11 | 递物、修物、点灯/刻字、双手操作 |
| 3 | 12–15 | 坐下、起身、物件特写衔接、克制反应 |

主角、母亲、阿宁优先；青松只制作手部与背影所需格，避免为了回忆大量绘制正脸。

### 7.3 Boss 入场与败退的低成本统一公式

1. 环境先变化 0.3–0.6 秒：水纹、木屑、信纸、灯焰、月影等先动。
2. Boss 用现有 idle/windup 帧入场，位移或缩放 0.4–0.8 秒。
3. 招牌物件最后落位 0.2 秒：古桥、量水碑、棋局、旧食盆等。
4. 战斗开始后才启用实时输入；剧情文本绝不盖掉红色预警。
5. 败退沿用现有 defeated 帧，再让环境恢复，不使用统一爆碎模板。

### 7.4 音效优先级

- 每个 Boss 一个可识别“生活声”：铃、木榫、报时鼓、炉呼吸、谷粒、风囊、信纸、砂、双轮、水滴、棋子。
- 战斗 bark 可以没有配音，先以短文本和动作声完成；配音不是本次可玩性的前置依赖。
- b12 读家书时只留纸张声；b15 空船后只留水声；b19 收棋只留棋子声；结尾吃面保留锅盖与碗筷声。

## 9. 工程接入方案

### 9.1 正式数据与界面事实源

- `data/adventure-campaign.v1.json`：正式九章、关卡 story、tactics、world_change、奖励和前置。
- `data/pixel_campaign_bosses.json`：二十 Boss 详细身世、视觉和归衡说明；需与本母版同步，不可只改旧文档。
- `data/combat/pr4_boss_signatures.json`：招式节拍与预警；只补 bark/演出引用，不改变已验收判定。
- `scripts/story_panel.gd`：已支持多句对白、回看、上一句/继续和节点存档，可直接承接扩充后的章节 nodes。
- `scripts/expedition_lobby.gd`：当前展示 Boss 图、推荐、战术和奖励，但尚未展示服务端已下发的 `stage.story`；是战前剧情入口。
- `scripts/expedition_view.gd`：由服务端 waiting/countdown/fighting 等状态驱动，不允许用长剧情覆盖已计时战斗。

### 9.2 推荐新增结构

在正式 campaign 的每个 stage 增加可选字段，保持旧存档兼容：

```json
{
  "scene_id": "wood_b03_old_tree",
  "prelude": "wood_b03_prelude",
  "entrance": "boss_enter_protect_tree",
  "resolution": "wood_b03_resolution",
  "barks": ["phase_1", "enrage"],
  "props": ["height_marks", "fallen_branch"],
  "story_flags": ["seen_height_marks"],
  "recommended_after": ["b02"]
}
```

另建 `data/story-scenes.v1.json` 保存镜头、角色、动作、道具、文本和触发条件；不要把整段镜头脚本塞进 tactics。章节 intro/closure 继续沿用现有多句 dialogue，不另造一套存档。

### 9.3 播放顺序

1. 玩家在秘境列表点“进入秘境”。
2. 若 prelude 未看过，打开战前剧情面板；允许逐句继续与回看，跳过时只跳演出，不跳规则或奖励。
3. 关闭剧情后才调用 `expedition_start`。
4. 战斗 waiting/countdown 播放 0.8–1.6 秒 Boss 入场；fighting 后完全服从服务端输入和计时。
5. 战斗 bark 只由阶段、激怒和破势触发；同一场不重复刷屏。
6. 首通结算后播放 resolution；再战默认跳过，可在图鉴回看。
7. 回村物件由首通与 story flag 驱动，重进游戏仍保持，不重复发奖励。

### 9.4 存档与幂等

- 章节 nodes 和首通继续使用现有服务端记录。
- 新增 `story_scene_states` 或等价通用 story flag 表：`cultivator_id + scene_id` 唯一，记录首次播放时间，不记录付费/奖励。
- 关键真相旗标建议：`seen_tree_marks`、`read_father_letter`、`met_aning_water`、`heard_empty_boat`、`visited_home_side`、`finished_finale`。
- 结尾必须同时检查 `b19 cleared` 与回村场景首次触发；断线重连后可从回村场景恢复，不重复播放 Boss 战。
- 可选 side 不阻塞旧玩家进入 echo/finale；若未完成 side，终章只少一段针线回收，不补发强制剧透。
- 男女主角与阿宁外观只切换显示资源：`protagonist_variant`、`companion_variant` 独立保存，默认读取已有角色外观选择；剧情 scene_id、奖励和旗标在所有组合下保持一致。
- 同一份台词使用“孩子”等中性称呼，角色名、立绘、配音和动作由 variant 资源表解析，不复制四套 campaign JSON。

### 9.5 首页与回村

- 序章、木后、火后、土后、金后、水后、旁篇后、终章后均更新同一住宅场景，而不是新增八张互不一致的家。
- 可复用同一机位，逐次改变：包袱是否还在、干粮袋数量、门灯、针线、家书位置、阿宁是否出现、桌上碗筷数量。
- 完成 b19 后，正式主线目标从“修复五域”切到“回家吃饭”，再开放长期经营与二十长廊，不弹主题总结。

## 11. 验收清单

### 11.1 剧情连续性

- [ ] 玩家能在不读外部文档的情况下理解：离家原因、五域目标、阿宁为何出现、执衡为何停住时间。
- [ ] 二十个 Boss 都由场景动作引出，没有凭空刷在玩家面前。
- [ ] 每关至少有一个“原本在守什么”的可见证据，不依赖打完后的长说明。
- [ ] 木域前不发布死讯；金域只给不安；水域才给空船；最终回村才完成情绪回收。
- [ ] 父亲、母亲、阿宁三线各自至少三次铺垫、一次变义、一次回收。
- [ ] 母亲不是只在家哭；阿宁不是只被救；青松不是完美圣人；执衡不是临终洗白。
- [ ] 结尾没有父亲现身、主题总结或复活式圆满。

### 11.2 角色与动画

- [ ] 三视图均为同一角色，头顶、肩线、腰线、脚底一致，正侧背服装结构能互相对应。
- [ ] 新角色缩小到实机尺寸后，仍能凭剪影、主色和道具认出。
- [ ] 手部与道具接触成立，递信、缝衣、拿碗、修绳不出现悬空或穿插。
- [ ] 剧情动作不覆盖战斗 16 帧映射，不改变攻击判定和受击时间。
- [ ] Boss 激怒仍保留主角、Boss 和红色预警的可读性，不用全屏血色或彩光遮挡。

### 11.3 工程与存档

- [ ] 首次进入、跳过、逐句回看、首通、再战、断线重连均不会重复发奖励或卡死。
- [ ] 旧存档没有新 scene flag 时可安全补看，不强制清档。
- [ ] 可选旁篇未完成时不会阻断主线，也不会让终章台词引用玩家未见过的事件。
- [ ] 服务端战役进度与二十长廊顺序解锁仍是两套明确接口，不互相误写。
- [ ] 战斗计时只在服务端允许的阶段运行，剧情面板不会暂停客户端却漏停服务端。
- [ ] 手机端剧情文字、继续/跳过按钮和触控操作不重叠；减少闪烁设置对入场与激怒同样生效。
- [ ] 男/女主角 × 男/女阿宁四种显示组合均能完成全主线；事件、奖励、伏笔和结局相同，立绘、称呼与配音正确，不出现性别错配或某组合被强制改写关系。

### 11.4 必做实机片段

1. 新档：序章分干粮 → b00 → 木域树痕。
2. 金域：b10 风信 → b12 家书与阿宁落款。
3. 水域：b13 阿宁重逢 → b14 袖口 → b15 空船。
4. 旁篇：b16 缝衣 → b17 门灯；另测跳过旁篇的终章差异。
5. 共域：阿宁地图与同款干粮。
6. 终章：棋桌入场 → 三段战斗 bark → 收棋 → 回村吃面。
7. 重进游戏：结尾旗标、物件和碗筷状态保持，再战 b19 不强制重播长剧情。
