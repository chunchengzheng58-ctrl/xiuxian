# 网页首屏加载动画

`game.html` 在引擎脚本和游戏资源开始下载前显示标题卡与灵气阵法动画。加载卡展示真实进度、资源大小与采样速度；完成后提示初始化，不强制延长等待时间。

每次 Godot Web 导出后，必须执行：

```powershell
node tools/prepare-web-loading.mjs <网页导出目录>
```

将生成的 `loading/` 目录与导出的 HTML、JS、WASM、PCK 一起发布到 `/web-<完整提交号>/`，HTML 的 base 指向该目录。`game-cache-sw.js` 另发布到网站根目录，设置 `Cache-Control: no-cache`。版本资源设置 `public, max-age=31536000, immutable`，首页保持 `no-cache`。

页面仅缓存同源带完整版本号的公共游戏资源，不缓存 API、账号、健康数据或部分下载响应。相同版本优先读取 CacheStorage；新版本使用新地址。缓存不可用或存储空间不足时退回正常网络加载。浏览器清理数据、隐私模式、更换浏览器或设备后仍需重新下载；缓存不能免去引擎初始化。

登录页勾选“记住账号并保持登录（此设备）”后，仅保存账号名、服务地址和服务端会话令牌，不保存密码。重新进入时通过 `/api/v2/auth/me` 校验令牌，再同步角色；失效后需重新登录。取消勾选或退出账号会清除保存的令牌。

首次网络下载和 CacheStorage 写入由网页管理，不交给后台 worker 的长任务。根目录 worker 仅替换旧版 worker，不拦截请求，避免慢网络触发后台事件时限。导出辅助脚本还会补上 Godot 下载流的错误传递，使网络中断能够重试或报错。
