## 图片 1：0 秒首帧（生成目标：云海俯瞰仙村）

- 工具：图片生成，Seedream 5.5，1920×1080（16:9）
- 输入图 1：`assets/pixel/village-background.png`（画风与场景语汇参考）

```text
参考图1（village-background.png）提供画风与场景语汇：32位精细像素块面、暖金色晨光、青灰瓦顶木构飞檐、成串灯笼、石拱桥与碧色溪流、山巅金色渡劫圆台、远处紫色魔龙传送门。不继承其平视三分之四俯角构图，也不继承其地平线高度与画面留白。输出为一整幅 16:9 电影感像素场景。

画面内容：从云海正上方约55度俯角俯瞰一座悬于云海之上的仙村。村落沿山脊铺开，左侧为层层叠叠的青灰色瓦顶与飞檐，屋脊上有薄薄晨霜；成串暖金灯笼挂在檐下，灯光把瓦面照出橙金色反光。画面中偏右上方是金色渡劫圆台，地面刻着环形阵纹，一道柔和的金白光柱从台心垂直升入天空。右上角更远处，一座暗紫色魔龙石门半隐在云雾中，紫色微光只在门洞内隐约透出。画面下方有一条碧色溪流穿过村落，石拱桥横跨其上，溪面有细碎反光。村落四周是翻涌的云海与层叠的远山、细长瀑布，最远处几座山峰上有小亭。

电影感处理：平行的晨光斜射形成可见的体积光束，前层云絮虚化形成浅景深前景，中景村落清晰，远景山峦逐层被蓝灰雾气吞没；画面整体暖金与冷蓝对比，暗部略偏青，高光带轻微柔光晕染，但像素方块必须清晰锐利、边缘方正，32位像素RPG的颗粒感贯穿全图，不能是3D渲染、不能是平滑数字绘画、不能有摩尔纹或模糊插值。

严格禁止：画面中不出现任何人物、动物、飞鸟；不出现任何文字、数字、招牌字、UI、血条、按钮、水印、边框、署名；不出现相机镜头畸变或鱼眼效果。
```

### 后期：像素网格化（本机 ffmpeg）

```powershell
ffmpeg -i sources/opening-frame-raw.png `
  -vf "scale=640:360:flags=area,eq=saturation=1.12:contrast=1.05:brightness=0.01,scale=1920:1080:flags=neighbor" `
  op-opening-frame.png
```

说明：生成模型在 2048 宽下难以稳定保持真实像素网格，改用「降采样到有效像素分辨率 → 最近邻放大」得到确定性的 3px 方块。`sources/` 内保留平滑原稿与一次像素重绘尝试。

## 图片 2：片尾标题卡

- 工具：图片生成，Seedream 5.5，1920×1080（16:9）
- 输入图 1：`assets/pixel/village-background.png`（仅取配色与像素质感）

```text
参考图1（village-background.png）仅提供配色与像素质感：暖金、青灰瓦色、靛蓝阴影，以及32位像素块面的清晰程度。不继承其任何场景、建筑、构图或人物。输出为 16:9 游戏片尾标题卡，纯平面设计画面。

背景：深墨色到靛青的垂直渐变，中心偏上有一圈极淡的金色环形阵纹残影，四周有若隐若现的像素云絮，颗粒细密，整体压暗、留出大量安静的负空间。

主标题：画面正中偏下，一行六个字“疯狂修仙，中”，像素书法字形——笔画结构是毛笔行楷的起收与顿挫，笔身由整齐的方形像素块构成，边缘可见阶梯状像素台阶；字色为暖金到浅金渐变，带窄金边与极轻的暖色外发光，整体占画面宽度约六成，字距均匀，六个字与全角逗号完整无缺、笔画清晰可辨、无错字无变形。

小字：主标题正下方约一个字高处，一行细体小字“五域归衡 · 二十秘境”，颜色为低饱和浅金，字号约为主标题高度的八分之一，字距略宽。

严格禁止：不出现英文、不出现额外标语、不出现按钮、不出现“点击开始”、不出现进度条、不出现二维码、不出现水印、不出现边框或角标；文字不得重叠、不得被裁切、不得出现乱码或多余笔画。
```

版本：第 1 版即采用，标题六字与全角逗号、副标均核对无误。

## 视频：23 秒连续镜头（成片 25 秒 = 23 秒画面 + 2 秒标题卡）

- 工具：图生视频，Seedance 2.5，16:9，23 秒，1 条
- 输入图 1：`op-opening-frame.png` 作为 0 秒首帧

### 1. 输入资产定位与 0 秒基准

<图片1> 是本次 0 秒首帧，锁定云海俯瞰仙村的整体构图、左侧层叠青灰瓦顶民居群与檐下灯笼的位置、右侧山脊金色渡劫圆台与自台心垂直升起的金白光柱、右上角半隐云雾的暗紫石门、下方横跨碧色溪流的石拱桥，以及四周云海与层叠远山瀑布的位置关系；同时锁定 32 位像素美术的块面密度与暖金—靛青配色。不继承任何文字、界面与水印（图中本无）。无音频输入。0 秒画面：晨光中的仙村悬于云海之上，光柱静止直冲天空，云海缓慢翻涌，镜头尚未开始位移。

### 2. 参考主体绑定与生成目标

本片是一条连续向下推进的长镜头，从云海之上降到村中桥头，依次完成「看见整个世界 — 落进人间烟火 — 看见一个修士 — 看他拔剑破云」。全片严格保持 <图片1> 的像素美术语言：清晰的方形像素块、硬边云团、每处 3–4 级色阶、暖金高光与靛青暗部；云层高光用阶梯状像素带，不用真实柔光晕散。运镜是电影感的缓慢下降、轻侧滚与末段微微上仰，但画面始终是像素，不是写实三维渲染。主角只以背影出现：三头身像素剑修，褐色高马尾、靛蓝发带、象牙白外袍配深蓝衣缘、背负长剑。

### 3. 逐时间段动作、声音与脚本

0–5 秒：机位保持在 <图片1> 的俯瞰角度，云海自左向右缓慢流动，前层云片以半透明像素云团掠过画面下缘；金色光柱微微脉动，光柱内部有向上飘升的亮点像素。镜头极缓慢开始前推并轻微下降。

5–10 秒：镜头匀速下降穿过第一层云，云雾在画面下三分之一处被推开、云缘呈阶梯状像素台阶；远山、细长瀑布与山顶小亭依次从云里露出，屋脊飞檐由远及近。灯笼一盏接一盏亮起，暖光以灯心为中心的像素环逐层加亮。镜头带约 4 度的缓慢侧滚。

10–14 秒：镜头降到与屋檐齐平，贴着瓦当与檐角向前滑行；可见晒着的药草、转过一格的水车、溪面上一排排水平亮色像素短线。镜头速度略加快，产生贴地飞行的速度感。

14–18 秒：镜头越过屋脊落向石拱桥，桥头出现一个背影：三头身像素剑修，白袍深蓝衣缘、褐发高马尾与靛蓝发带，背负长剑；衣袂与发带被风压低又扬起。他静止站立，随后缓慢抬头望向远处的金色光柱。镜头在他身后减速停住，只余轻微呼吸式浮动。

18–22 秒：光柱骤然增亮，光带变宽；一道青白剑气从背后剑鞘方向激射而出，贴着画面斜向掠过，剑气所过之处云海被切成两半并短暂分开；右上角暗紫石门被剑气惊动，门洞内紫光一闪，随即熄灭并沉回雾里。镜头轻微上仰跟随剑气。

22–23 秒：剑气远去，金色光芒从光柱方向迅速扩张，吞没画面，最后收成一团纯深墨色。画面平稳保持为纯深墨底色，不再有建筑、云海与光。

声音：全片不使用人声与台词，只保留环境声。一条缓慢的晨风与远处水声底噪贯穿全片；5–10 秒灯笼亮起时加入一声轻铃；18–22 秒加入短促的剑气破空与云层被切开的低频轰鸣；22 秒随金光吞没收成一个短促钟磬余音，随后留白。

### 4. 转场与尾态收束

段内不切镜，靠连续下降完成空间转移：由高到低、由远景到人物、由静到动。结束状态为纯深墨色平稳底色，供后期在此叠加片尾标题卡；不额外追加定格，不出现任何文字。

### 5. 全片一致性与禁区

- 全片像素块面大小统一，不得中途变成平滑写实或三维渲染。
- 建筑布局、光柱与紫色石门的位置关系不得跳变；石桥与溪流不得位移。
- 主角全程只出现一次背影，不出现正脸、不对镜头转身、不做夸张动作；不出现第二个角色。
- 不出现任何文字、数字、招牌、UI、血条、按钮、水印、边框。
- 不出现镜头畸变、鱼眼、真实镜头光斑与柔焦；不用模糊表现景深。
- 结尾必须收干净到深墨底色，不要在墨底上再画出建筑残影。
